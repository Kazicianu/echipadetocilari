# Logos

The mark is a nerd drawn in white lines (round glasses, bow tie, three strands of hair) on an `orange-logo` blob. There is no wordmark; set the name "Echipa de Tocilari" in Montserrat next to it when a name is needed.

- `Logo_Echipa_de_Tocilari-e1708028624694.webp`: the logo used in the header and footer (836 × 870, transparent). The header shows it in an 80px-wide box, 75px tall; the footer at a third of its column. Link it to the homepage with `alt="Logo Echipa de Tocilari"`.
- `Logo_Echipa_de_Tocilari-1024x1024.webp`: the same mark centred on a transparent 1024 × 1024 square, for square slots such as social avatars and structured data.

Use the files as they are: no recolouring, outlines, shadows or redrawn versions. Place the logo on `white` or very light backgrounds; the orange blob carries its own contrast for the white lines.
