# Icons

Single-ink icons copied from the live pages. On the site they are inline SVG painted by CSS (`color` and `fill` set to `orange`, or `currentColor`); these files carry the ink the site renders so they preview correctly. When you inline one, drop the colour attributes on the root `<svg>` and let CSS colour it. Mark icons `aria-hidden="true"` when text next to them says the same thing.

Service icons, 75 × 66 with a faint blob behind the drawing (the first path, at 5% opacity), ink `orange` (homepage service cards and the maintenance band):

Interface glyphs from Font Awesome 5 Free (Elementor inline SVG, CC BY 4.0), shown at 1em:

- `ui-arrow-up.svg`: back-to-top; rendered `white-warm` on `orange` (file ink: `ink`).
- `ui-arrow-right.svg`: trailing icon of the "Despre noi" button; rendered `white-warm` (file ink: `ink`).
- `ui-chevron-down.svg`, `ui-chevron-up.svg`: homepage FAQ toggles, ink `orange`.
- `social-facebook.svg`, `social-linkedin.svg`: footer, ink `orange`, `accent` on hover.

Hand-drawn:

- `swipe-arrow.svg`: the scribbled arrow under "Glisează și vezi mai mult" on the mobile homepage, ink `ink`, 1.6 stroke.

Three of these draw a diagonal arrow, which the content rules forbid: `service-seo.svg` (rising chart), `service-google-ads.svg` (coin with a rising arrow) and `about-overview.svg` (target with an arrow). They are on the live pages today; do not use them in new work.
