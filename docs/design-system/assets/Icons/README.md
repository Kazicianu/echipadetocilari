# Icons

Single-ink icons copied from the four pages, the header and the footer. On the site they are inline SVG coloured by CSS (`currentColor`); each file carries the ink the site renders so it previews correctly. When you inline one, drop the colour attributes on the root `<svg>` and let CSS colour it. Mark icons `aria-hidden="true"` when text next to them says the same thing.

Service marks, 75 × 66 with a faint blob behind the drawing (the first path, at 5% opacity), ink `orange`. Homepage service tiles (65px), the maintenance band (52px) and the Google Ads related cards (64 × 56):

- `service-website.svg`, `service-shop.svg`, `service-apps.svg`, `service-seo.svg`, `service-google-ads.svg`, `service-facebook-ads.svg`, `service-maintenance.svg`

Services submenu, 24px grid, 1.6 stroke, round caps and joins, ink `orange` (shown at 22px in a round 40px `peach-menu` disc; `white` on an `orange` disc for the hovered or current service):

- `menu-website.svg`, `menu-shop.svg`, `menu-apps.svg`, `menu-seo.svg`, `menu-google-ads.svg`, `menu-facebook-ads.svg` (a thumbs-up), `menu-maintenance.svg`

Store page, 24px grid, round caps and joins:

- Ticket icons, 1.8 stroke, ink `orange-deep`: `ticket-store.svg` (also the first metro stop, in `ink`), `ticket-chat.svg`, `ticket-cart.svg`.
- `scissors.svg`, 2 stroke: the tear of a ticket. File ink `ink`; the site draws it `white` on `orange`.
- Metro stops, 1.8 stroke, ink `ink`: `stop-catalog.svg`, `stop-search.svg`, `stop-payment.svg`, `stop-delivery.svg`, `stop-panel.svg` (the destination, `white` on `orange`).
- "După lansare" cards, 1.5 stroke, ink `orange-deep` on a `peach` disc: `card-seo.svg`, `card-ads.svg`, `card-maintenance.svg`.
- Hero arrow chips, 1.8 stroke, ink `ink`: `arrow-right-line.svg`, `arrow-down-line.svg`.
- `plus.svg`, 3.2 stroke: the "Pe lângă preț" list. File ink `ink`; the site draws it in `field` on an `orange` disc.

Google Ads page, 24px grid:

- `check.svg` (2.5 stroke, ink `orange`): included features in the comparison table; at 3 stroke and `white` it is the check on keyword rows and in store checklists.
- `dash.svg` (2 stroke, ink `mute`): features not included in the comparison table.
- `cross.svg` (3 stroke, ink `ink-soft`): excluded keywords.
- `refresh.svg` (1.6 stroke, ink `orange`): the recurring optimisation step and card.

Glyphs from Font Awesome 5 Free (CC BY 4.0), shown at 1em:

- `check-circle.svg`: the check before every price-list line (store, /creare-site-web/, Google Ads plans), ink `check-green`, 15px.
- `ui-arrow-up.svg`: back-to-top; rendered `white-warm` on `orange` (file ink: `ink`).
- `ui-arrow-right.svg`: after the "Despre noi" label; rendered `white-warm` (file ink: `ink`).
- `ui-chevron-down.svg`: the "Compară pachetele" toggle on Google Ads, ink `orange`.
- `social-facebook.svg`, `social-linkedin.svg`: footer, ink `orange`, `accent` on hover.

Hand-drawn:

- `swipe-arrow.svg`: the scribbled arrow under "Glisează și vezi mai mult" on phones, ink `ink`, 1.6 stroke.

Two service marks draw a diagonal arrow, which the content rules forbid: `service-seo.svg` (rising chart) and `service-google-ads.svg` (coin with a rising arrow). They are on the homepage and the Google Ads related cards today; do not use them in new work.
