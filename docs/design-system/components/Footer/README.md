# Footer

The site footer: logo, company details, the important pages, social links and copyright.

Markup: `footer.ect-footer` with `.ect-footer__top` (`.ect-footer__logo`, `.ect-footer__info`, `.ect-footer__links`) and `.ect-footer__bottom` (`p.ect-footer__follow` with `ul.ect-footer__social`, and `p.ect-footer__copy`).

- Company block: "Echipa de Tocilari SRL", the address in Bucharest, the site, contact@echipadetocilari.ro, CUI and trade register number, 16px/1.7 in `ink` (15px on tablet).
- Pages: Creare site web, Servicii SEO, Administrare site, Contact, 16px with 2em line height.
- Social: Facebook and LinkedIn icons in `orange` (`accent` on hover), 44px targets. Give each link an accessible name (`aria-label="Facebook"`).
- The bottom row sits on a 1px `line` rule with 50px above; the copyright is 14px.

Hand-written from the Elementor footer template (post 3355).
