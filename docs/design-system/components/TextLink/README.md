# TextLink

An underlined text link in `ink` with an orange underline, for inline links and secondary actions.

- `ect-link`: the About style, 15px, weight 500, underline at 60% `orange` 5px below the text, turning `orange` on hover. Use it alone on a line under a card or a paragraph; a trailing " ↓" marks an in-page jump.
- `ect-link--strong`: the Google Ads style for a link inside running text: inherits the size, weight 600, a solid `orange` underline 4px below.
- Focus draws a 3px `ink` outline 5px out.

Write the destination, not "click here": "Vezi ce ne iese când lucrăm împreună", "Descoperă serviciile noastre". Hand-written from `ect-pages/about.css` (`.ect-about-text-link`) and `google-ads.css` (`.gads-measure a`).
